# Portal CA — Ecosistemas Inteligentes e Innovación en Turismo

Prototipo funcional Fase 1.

## Abrir
Abra `index.html` en un navegador. Para publicación puede alojarse como sitio estático en GitHub Pages, Netlify, Vercel o un servidor institucional.

## Editar contenido
Los datos iniciales están en `data.js`. Los campos sin información real se muestran como “Información pendiente de incorporar”.

## Siguiente fase sugerida
Migrar el modelo de datos a un CMS/base de datos, incorporar autenticación y roles, editor de publicaciones, relaciones entre proyectos/productos/evidencias, comentarios moderados y panel de administración.
